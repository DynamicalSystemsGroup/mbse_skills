# Community conduct

Participants should treat one another with respect, critique engineering claims with evidence, and welcome questions and differing experience. This applies to issues, pull requests, discussions and other project spaces.

Harassment, discrimination, threats, doxxing, unwanted sexual attention and repeated personal attacks are unacceptable. Respect requests to stop and keep confidential information out of public conversations.

Repository administrators handle conduct concerns and may remove content, close a discussion, restrict participation or remove access according to the situation. They should explain decisions where safe and protect reporters' privacy. A person involved in a complaint should not decide its outcome.

For a sensitive conduct concern, use a maintainer's publicly offered private contact or GitHub's abuse-reporting tools. If no private contact is available, request one without posting incident details publicly. Security vulnerabilities use [private security reporting](SECURITY.md). No dedicated conduct response service or response deadline is promised.

This is an original project policy, not a claim of adoption of an external code of conduct.
