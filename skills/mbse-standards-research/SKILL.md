# MBSE Standards Research

## Clarification and human review

Engineers retain responsibility for engineering decisions. Clarify unresolved source edition, applicability or a disputed normative interpretation when they could change the result; reuse established answers. Keep dependent conclusions pending while continuing authorized drafting or investigation. Present changed engineering artifacts as proposed or awaiting review, preserving existing source and approval status. Request the responsible human's review before adopting changed obligations, design decisions or adequacy claims. Report the artifact revision, evidence scope, open questions and decision needed; record acceptance only when actually supplied by an identified authority. A passing tool check, silence or agent agreement is not human acceptance.


Answer a bounded standards question with a traceable source and an explicit interpretation.

1. Identify the standard or guidance edition, question, scope and project applicability. Check existing source records before retrieving anything new.
2. Use the issuing body's official version page to select the artifact. Record title, version, document identity, URL, retrieval date, and byte hash when locally available. Consult [source selection](references/source-selection.md) for source authority, edition and access distinctions.
3. Read the relevant clause and dependencies in context. Separate normative wording, informative example, library definition, and our interpretation. Check the original page when extracted tables or symbols are ambiguous.
4. Explain the rule in original wording, linking the clause. Record applicability, exceptions, ambiguity, and conflicts with other sources. If the needed source is inaccessible, report the gap rather than reconstructing it.
5. For a test expectation, specify what the rule predicts and the observation needed. A tool's behavior can challenge an interpretation; agreement among tools does not establish the rule.

Deliver a source record and a bounded answer with confidence and unresolved questions. Access to text is not permission to redistribute it. Preserve document notices; prefer original summaries and source links.
