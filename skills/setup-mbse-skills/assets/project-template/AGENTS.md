# Engineering project instructions

For MBSE tasks, read docs/mbse-project.md and the relevant project artifacts before selecting practices. Apply its selected process, tailoring and artifact/review conventions; keep unresolved choices open. Preserve proposed/open/accepted distinctions and existing evidence. A tool result supports only its observed scope.

Engineers retain responsibility. Ask about material unresolved assumptions, criteria or authority before relying on dependent conclusions. Continue authorized drafts and investigation where possible. Request the responsible human's review before adoption of changed engineering obligations, design decisions or adequacy claims; retain actual reviewer, artifact revision, decision and conditions. Tool success and agent agreement do not establish human acceptance.
